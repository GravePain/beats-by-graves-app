# Beats by Graves

**A full synth and beat sequencer in a single HTML file — no installs, no build, no servers.**

▶ **Play it now:** https://gravepain.github.io/beats-by-graves-app/

A from-scratch subtractive synthesizer with 57 presets, a channel-rack step sequencer, a piano roll with real-song
chord, melody and riff generators, a per-channel effects rack, a playlist arranger, and WAV export — all on the Web
Audio API, in one ~180 KB page that works offline the moment it loads.

## Get it

- **Play in your browser:** the link above.
- **Download:** grab `beats-by-graves.html` from the [latest release](../../releases/latest) and double-click it (Chrome or Edge).
